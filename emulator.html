muse_pwa — Device preview

Test the Step 1 UI as a webpage and as a mobile webapp, without changing the app itself. The preview loads the real index.html in an iframe, so it always shows the current code.

Open app

How this works, and its limits. The mobile frame uses the model's CSS viewport size, so the app's mobile layout (sidebar hidden, drawer toggle) triggers exactly as it would in a narrow browser window. It is still an approximation: it does not simulate touch gestures, safe-area insets, or a real phone's performance. For a real-device check, open index.html itself on that phone (same server as this page — local serve, Codespaces port forwarding, or Vercel), or use the “Open app” button above on the phone. Step 1 chats are in-memory per frame, so in “Both” view the desktop and mobile previews do not share messages.
